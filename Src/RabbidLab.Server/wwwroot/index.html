    Assign the MSI under Computer Configuration > Policies > Software Settings > Software Installation. Add the template to PolicyDefinitions, then set Server address and Server certificate fingerprint under Administrative Templates > Rabbid Lab > Client.

    New group

    A group can be empty until you put something in it.

    A browser lets a page open one tab for each click until pop-ups are allowed for it. Allow them for this console once, and Open all opens a whole group at a time from then on.

    1. Click the pop-up blocked icon at the right end of the address bar.
    2. Pick Always allow pop-ups and redirects from , then Done.
    3. Click below.

    No icon there? In the browser's settings, search for Pop-ups and redirects and add under Allowed to send pop-ups and use redirects.

    Links settings

    How often Rabbid Lab asks each link whether it answers, and how long one has to be quiet before it shows as down. A change is saved as you make it.

    Export

    Links are checked while the console is open on this page. For checks around the clock, with email when something goes down, add a sensor.

    Export saves every link with its icon, the groups in their order and these settings as one file. Import adds what's in a file like it beside what's here: a link whose address is already here is left as it is.

    The client can't be uninstalled on its computer until you allow it here. That keeps anything on the computer from removing it on its own.

    Uninstall it nowThe client takes itself off the computer within a minute. The computer then shows as Offline: remove it from the list.
    Allow uninstalling for an hourSomeone at the computer can then uninstall it from the client's window or from Windows' installed apps.
